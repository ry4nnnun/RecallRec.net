Get in

Join in four steps

Ask the server owner for the friend kit. It has the patch files and a settings file that already points at our server.

  1. Install Rec Room 2026

    You need the 2026 client, build 20260323.14. Other versions won't connect.

  2. Drop in the friend kit

    Put 2026patch.dll, Injector.exe, 2026patch.ini and the two launchers in the folder with RecRoom.exe.

  3. Launch through the patch

    Run RecRoomScreen.bat to play on a monitor, or RecRoomVR.bat for VR. The launcher starts the patch before the game.

  4. Say hi in the Rec Center

    Make an account the first time you load in, then find us in the Rec Center or check the watch for friends online.
